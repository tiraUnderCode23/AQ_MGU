**تاريخ المراجعة:** 2026-11-20

**مرجع المقارنة الثابت:** `16b44f49f3451ff9f92ab326acedbf9f3a8d9303`

**نوع العمل:** مراجعة ملفات وبيانات محفوظة، مع حساب حجم وبصمة الحزمتين المحليتين كملفين مغلقين. لم تُستخرج أرشيفات، ولم تُقرأ محتويات SDK أو تُنفذ شيفرة تطبيق أو عملية تثبيت.

## النتيجة

كل معرّفات التطبيقات والمساعدات في مجموعات المقارنة الثلاث موجودة في الشجرة المرجعية: 288 معرّفًا من main التاريخي، و39 معرّفًا من فرع الألعاب التاريخي، و61 معرّفًا من نسخة مراجعة 17 نوفمبر. لم يُعثر داخل النطاق المحلي المفحوص على تطبيق آخر من مصدر BCS غير `bcs_store@3.4.5`. هذه نتيجة تغطية للنطاق المفحوص، وليست حصرًا لكل منتجات الناشر خارج هذه الملفات.

حزمتا `aq_lights@4.6.1` و`aq_lights@4.6.2` محفوظتان الآن بصفتهما **مراجع محلية للبيانات فقط** في [السجل الجديد](../data/local-app-artifacts-20261120.json). لا يضيف السجل أصل إصدار أو رابط تنزيل عامًا أو صفًا إلى كتالوج Store. التطبيق الكامل لا يزال خارج الكتالوج؛ مساهمة الواجهة المستقلة موجودة أصلًا في [contrib/aq-lights-ui](../contrib/aq-lights-ui/README.md).

### ما تغيّر بين 4.6.1 و4.6.2

في بيانات 4.6.1 المرتبطة بالمجلد المفكوك مسبقًا، إصدار package وmeta هو 4.6.1، بينما إصدار RHMI في المصدر 3.1.0 وفي البيانات المولّدة 4.6.0. هذه ملاحظة عدم اتساق حقيقية تخص ذلك المتغير.

أما بيانات 4.6.2 في `aq_lights_original_staged` فتتفق في package وmeta وapp-spec وRHMI الأصلي والمولّد على 4.6.2. لذلك **لا يصح إبقاء اختلاف الإصدار مانعًا منسوبًا إلى الحزمة المصححة 4.6.2**. تعلن meta قيمة ID7، ومحددات RHMI ومجلد UI المرصود يخصّان ID7 فقط. لم يثبت دعم ID8 لهذه البايتات.

يبقى سجل 4.6.0 القديم محفوظًا بصورة منفصلة في [استثناءات التغطية](../data/aq-app-coverage-exceptions.json)، مع بصمة ملاحظته الأصلية `2b9d3ff08a447f2c9493bf5daec9ff3f1ef36b4dbcc20a4ef703390b9b2f5fa5` ومرجعه [تقرير 19 نوفمبر](AQ_APPS_COVERAGE_20261119_AR.md). هذه البصمة تربط ملاحظات قديمة في سجل التغطية، وليست SHA لحزمة 4.6.1 أو 4.6.2. لم يُغيّر استثناء `aa_cluster_companion`.

### حدود المساعدات غير المعلنة

لا تعلن بيانات التطبيق الكاملة المفحوصة حقول `requires` أو `mguRequires`، ولم يثبت منها حد رقمي لإصدار renderer أو inputgate. تسجل المراجعة ذلك بوضوح: **`UNDECLARED`**، دون تحويل غياب الحقل إلى حكم بأن التطبيق لا يحتاج مساعدات.

الحقل الرقمي المعروف هو محرك Node `>=8.7.0` في package الخاص بالتطبيق. الإشارة في الوثائق إلى `mgu-render/1` تخص بروتوكولًا وقدرات تفاوض اللمس/الواجهة، ولا تعني `mgu-render >= 1.0.0`. كذلك `meta.kit = 1` علامة تنسيق، وليست حد إصدار لمساعدة. محرك Node `>=18` في مساهمة الواجهة المستقلة يخص تلك المساهمة، ولا يستبدل عقد التطبيق الكامل.

## 4. المنشأ وحقوق إعادة التوزيع

تحمل ملفات package المحلية للتطبيق الكامل `author: custom` و`license: UNLICENSED`. لم تُثبت المراجعة المحدودة للوثائق والبيانات وملفات الترخيص خارج SDK منحة مستقلة لإعادة توزيع التطبيق الكامل. لا تُعامل كلمة UNLICENSED العامة وحدها حكمًا حاسمًا على كل مادة أو دليل ملكية.

لوحظ وجود مسار `source/node_modules/oap-sdk` في مجموعتي المصدر المحليتين، كما يصف تقرير التسليم المحلي مواد SDK ومحتويات مشتقة. لم تُقرأ محتويات تلك المسارات أو تُنسخ أو تُستخرج. لا تُعد سلامة بصمة الحزمة دليلًا على السماح بنشر SDK أو الشيفرة الكاملة.

يحفظ `local_build/repair_patch_manifest.json` القيمة `publish: false`. تسجّل بوصفها حالة تاريخية ضمن منشأ الإصلاح، وليست قاعدة إذن جديدة تتغلب على تعليمات المستخدم الحالية. ومع ذلك، لا يثبت طلب النشر نفسه حقوق مواد الغير غير المثبتة في الأدلة.

التقرير المحلي `AQ_LIGHTS_MAIN_MERGE_REPORT_20261117_AR.md` يذكر قبول `MguPackage.prepare` ونجاح 28/28 فحص Node دون وحدة في 17 نوفمبر. هذه **نتائج تاريخية منسوبة إلى التقرير**؛ لم تُعد في هذه المراجعة، ولا تمثل تثبيتًا أو تشغيلًا لوحظ الآن.

ما أُدمج سابقًا ونجده في الشجرة المرجعية هو أربعة ملفات فقط تحت `contrib/aq-lights-ui`: README وpackage ووحدة UI واختبارها. يصف README هذه المساهمة بأنها مستقلة وغير قابلة للتثبيت كتطبيق كامل. لا تُحوّل هذه المساهمة إلى إثبات سماح بتوزيع الحزمة الأصلية أو SDK.
