# ملاحظات اللقطات والوسائط

- كل مجلد `_sources` مأخوذ من ملفات Git المتتبعة عند SHA المعروض في `data/sources.json`؛ لم تُنسخ ملفات `.git` أو BMW `oap-sdk` أو بيانات enrollment/مفاتيح أو تطبيقات `.mgu` التنفيذية.
- احتُفظ بالوثائق والصور ولقطات PNG/JPG/GIF المتتبعة في كل لقطة. قد يحتوي README upstream على روابط إلى ملفات صور لم تكن موجودة في commit المنشور (مثل بعض صور `third_party/doomgeneric/screenshots`)، أو إلى وثائق تطبيقات upstream غير موجودة داخل fork؛ لا يمكن استعادة ملف لم ينشره المصدر ضمن هذا snapshot، لذا أشير إلى المصدر الأصلي حيث أمكن.
- `data/external-sources.json` يسجل المشاريع ذات شروط تمنع إعادة التوزيع أو ذات ترخيص غير واضح؛ لم تُنسخ شيفرتها أو صورها.
- لا يُعد هذا الفحص اختبار build أو اختبار تثبيت أو توافق مركبة.
