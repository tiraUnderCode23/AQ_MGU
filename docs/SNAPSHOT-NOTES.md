# Source and Image Notes

- Source snapshots are pinned to the commit IDs in [`data/sources.json`](../data/sources.json).
- Application icons and screenshots in [`docs/assets/apps/`](assets/apps/) are copies of files published with those snapshots. The image index records the source path for every copy. No image has been retouched or relabelled.
- A few apps have no standalone upstream icon or screenshot. The catalog notes those gaps instead of presenting unrelated imagery as an app asset.
- Product localization files are retained as published so the apps can continue to offer their supported languages. The repository’s own documentation and catalog are in English.
