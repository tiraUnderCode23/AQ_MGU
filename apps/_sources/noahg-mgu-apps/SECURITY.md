# Security policy

Apps and services in this repository can interact with security-sensitive
head-unit or vehicle interfaces. Reports about unsafe path handling,
insufficient compatibility validation, backup or restore failures, privilege
boundaries, and unintended network exposure are especially useful.

Do not attach real VINs, credentials, provisioning data, firmware, donor apps,
captured FSCs, or other private vehicle material to a public issue. For a
non-sensitive report, open a GitHub issue. For a report containing sensitive
details, contact the maintainer through the Noahbg GitHub profile before public
disclosure.

Only the latest released version is supported.
