# iDrive 8 Features

Community apps for BMW iDrive and MGU Store, maintained by mazzahaker.

## xDriveRemover

Experimental app for reading xDrive diagnostics and requesting rear-wheel-drive mode. The MGU Store source is `mazzahaker/idrive8-features`, branch `main`.

The app includes iDrive 7 and iDrive 8 layouts. The drive request was accepted in an earlier build on one BMW M440i xDrive G23 with iDrive 8, with the engine off. The vehicle displayed a four-wheel-drive warning. The diagnostics showed the mode reported by the control unit. On-car validation of the changes in 0.1.26 is pending.
