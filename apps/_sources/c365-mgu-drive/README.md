# Drive

Своё приложение для MGU Store, iDrive 7 и iDrive 8. На экране: скорость, передача, температура масла и охлаждающей жидкости, пройденный путь, время в движении и средняя скорость.

Сборка на голове использует комплект [idrive7-apps](https://github.com/cauliflowermossgrape/idrive7-apps) (MIT, файл `LICENSE`). Кода BMW в репозитории нет.

## Установка с экрана

1. Выложи этот репозиторий на GitHub, публичным.
2. В машине: **Store → Settings → Add source**.
3. Введи `ivanivanov23022005-pixel/mgu-drive`.
4. Канал: ветка **main**.
5. **Drive → Install**.
6. На iDrive 8 перезапусти голову один раз. Плитка появляется после перезапуска.
