# M Drive

<img src="docs/mdrive/icon.png" width="140" alt="M Drive icon">

A motorsport dashboard for rooted BMW MGU head units with iDrive 7 or iDrive 8. Full-width RPM strip, engine oil, water temperature, gearbox oil, intake air and turbo pressure in bar. Includes four MHD map selectors, exhaust-flap controls and max cooling.

![M Drive dashboard in the offline emulator](docs/mdrive/dashboard.png)

## Install through MGU Store

1. Open **MGU Store → Settings → Add source**.
2. Enter **`grabandrey/m-drive-control`**.
3. Choose the **main** branch, or **Tags** for versioned updates.
4. Run **Check now**, find **M Drive**, and choose **Install**.
5. Let the Store install the required renderer/controller tools and follow its restart prompt. iDrive 8 applies installation at the next head-unit restart.

This is a **repo-tree source**, identified by the root `mgu-repo.json`. The Store builds it on your head unit using that unit's SDK. No SDK, keys, credentials or vehicle captures are published. No GitHub login is required for this public source. The Store must already be installed on a rooted MGU; this does not install on an unmodified factory head unit.

The source format follows the [MGU Store publishing guide](https://github.com/robertnisipeanu/mgu-store/blob/main/docs/PUBLISHING.md).

## Vehicle controls

Live data is the installed default. To enable commands, select **Settings → Vehicle controls → MHD+ DME**. An MHD+ equipped DME with compatible live features is required. Map buttons select existing map slots; they do not flash a tune.

The status beside **MHD MAP** shows sending, **DME accepted** after a matching positive acknowledgement, or **Not confirmed**. Acceptance is not active-map readback; no verified active-map feedback profile is bundled. Demo mode says **Demo – not sent** and sends no vehicle commands.

No commands run when the app opens. Unsupported or stale telemetry shows `--`. Turbo pressure uses the sport-display signal and the vehicle's pressure units, converted to bar. Water temperature is engine coolant temperature.

## Validation status

Offline builds generate both ID7 and ID8 interfaces. Control encoding, acknowledgement matching, demo isolation, stale telemetry and unit conversion have automated tests. The browser emulator has been checked at approximately 60 fps.

**Installation, telemetry and DME commands have not been validated on a physical head unit.** Vehicle/firmware support depends on the signals and MHD features available on your car. See [technical details and limitations](M-DRIVE.md).

## Local preview and checks

Requires Node.js and Python 3; no BMW SDK is needed for the preview.

```sh
node kit/tools/emu.js andrei_mdrive --port 8077
# Open http://localhost:8077
```

```sh
node kit/tools/test_mdrive.js
node kit/tools/test_mdrive_map_ack.js
node kit/tools/test_mdrive_boost.js
node kit/tools/test_mdrive_telemetry.js
python3 kit/tools/build.py --preview-only andrei_mdrive
python3 kit/tools/validate_mdrive_store.py
python3 kit/tools/package_mdrive.py
```

The preview under `dist/` is not installable. For offline installation, extract the source ZIP produced under `release/` onto a USB stick, preserving `mgu-repo/m-drive/mgu-repo.json`, then open the Store's USB page.
