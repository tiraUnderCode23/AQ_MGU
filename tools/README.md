# أدوات خارج تطبيقات MGU Store

- `mgu-store/`: المصدر الرسمي لمتجر MGU (راجع `tools/_sources/mgu-store/README.md`).
- `idrive7-8-ssh-root/`: أداة كمبيوتر مستقلة لإعداد SSH. اقرأ كل تحذيرات التفليش واحتفظ بنسخة احتياطية من الترميز؛ لم تُشغّل هنا.
- `mgu-plus/`: برنامج كمبيوتر يغلّف خطوات SSH ويثبت/يدير MGU Store؛ ليس تطبيقاً داخل السيارة. مرجع upstream المضمّن قديم مقارنة بأحدث SSH-root، لذا لا تستخدمه قبل تحديث/تدقيق `upstream.json`.

هذه المجلدات مرجع مصدر/وثائق ولا تظهر في `mgu-repo.json` كمكونات متجر. لم تُنفذ أي خطوة على مركبة أو خدمة SSH.
