# Desktop and Store Tools

These projects are listed separately from the in-car app catalog. They are desktop or head-unit tools, not additional apps in the catalog.

- [MGU Store](https://github.com/robertnisipeanu/mgu-store): the in-car app store. The source snapshot is under [`tools/_sources/mgu-store/`](./_sources/mgu-store/).
- [iDrive 7/8 SSH Root](https://github.com/cauliflowermossgrape/idrive7-8-ssh-root): a computer-side setup tool. Read the upstream warnings carefully; flashing can affect vehicle coding and digital keys. No vehicle operation was performed while preparing this catalog.
- [MGU Plus](https://github.com/deathwalker80/mgu-plus): a Windows desktop interface for SSH setup and Store management. It is not an in-car app. Check the upstream tracking file before relying on its version references.

These tools are kept outside `mgu-repo.json` and are not shown as installable catalog apps.
